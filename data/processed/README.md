# Derived frozen inputs

frozen_analysis contains the E0--E6 derived rankings, labels, query evidence, archived draws and summary artifacts from the fixed diagnostic run. baseline_reference contains the earlier frozen tables required for the explicitly labelled historical analyses and provenance. They are immutable reference inputs, not raw PrimeKG or complete CIViC snapshots.

Outputs are written to ../../code/results/generated. Core fields are explained in ../../docs/notes/data_dictionary.md; csv_schema_index.json lists every distributed CSV schema.
