evidencepath_v1.0.pdf is the final 16-page main paper; supplement_s1_v1.0.pdf is the 8-page technical companion. latex/ preserves the exact manuscript source and assets, with title-only figure/table captions. Compile EvidencePath.tex or Supplement_S1.tex from latex/ with a recent TeX Live installation or Tectonic. The paper remains self-contained; a separate companion does not imply an exception to a venue page limit.
